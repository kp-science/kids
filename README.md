เปิดใช้งาน: https://kp-science.github.io/kids/

## หลักที่ใช้กับทุกสื่อ

- เด็กไม่ต้องพิมพ์ ใช้ลากวาง/แตะเลือก และมีปุ่ม 🔊 อ่านออกเสียง
- ตัวเลือกสลับตำแหน่งทุกครั้ง มีตัวหลอกจริง ตรวจคำตอบด้วยระบบ ไม่ให้เด็กตัดสินเอง
- ภาพ: พื้นครีม กล่องขาวลอยเงานุ่ม สีพาสเทลอ่อนสลับกัน ตอบผิดใช้โทนพีชอ่อน
- ทำจบแล้วเรียก `KP.log({ kind, page, subject, title, score, total, stars, wrong })` เพื่อนับดาวและภารกิจ

## เพิ่มสื่อใหม่

1. วางไฟล์ HTML ในโฟลเดอร์วิชา แล้วใส่ `<script src="../common/progress.js"></script>` ก่อน `</body>`
2. เพิ่มรายการใน `MATERIALS` ของ `index.html` (วิชาใหม่ให้เพิ่มใน `SUBJECTS` และ `ORDER`)
3. ทดสอบขนาดไอแพดและมือถือ
4. **รัน `node tools/gen-sw.js`** เพื่อให้ไฟล์ใหม่ถูกเก็บไว้เล่นตอนไม่มีเน็ตด้วย (ลืมไม่ได้ ไม่งั้นหน้าใหม่จะเปิดไม่ได้ตอนเน็ตหลุด)
5. commit + push รอ 1–2 นาที

## หมายเหตุ

- ตั้ง noindex ไว้ ไม่ขึ้นใน Google แต่ใครมีลิงก์ก็เปิดได้
- ข้อมูลคะแนนทั้งหมดอยู่ในเครื่องที่ใช้ ไม่ส่งออกไปที่ไหน
- แยกจาก repo หลักของ KP Science โดยตั้งใจ
- **เล่นได้ตอนไม่มีเน็ต**: เปิดเว็บครั้งแรกตอนมีเน็ต เครื่องจะเก็บทุกหน้าไว้ (~3 MB) ครั้งต่อไปเปิดได้เลยแม้ไม่มีสัญญาณ
  เวลาอัปเดตเว็บ เครื่องจะได้ของใหม่ตอนเปิดครั้งถัดไป (เปิดรอบแรกอาจยังเห็นของเดิม รีเฟรชอีกครั้งจะขึ้น)
  บนไอแพด Safari อาจล้างของที่เก็บไว้ถ้าไม่ได้เปิดเว็บนานหลายวัน ต้องเปิดตอนมีเน็ตอีกครั้งหนึ่ง
