# ห้องเรียนที่บ้าน

สื่อฝึกสำหรับลูก รวมไว้ที่เดียว เปิดได้ทั้งคอมและไอแพด

เปิดใช้งาน: https://kp-science.github.io/kids/

## โครงสร้าง

```
index.html        หน้ารวมสื่อ (แก้รายการที่ตัวแปร MATERIALS ท้ายไฟล์)
chinese/          ภาษาจีน
physics/          ฟิสิกส์
math/             คณิตศาสตร์
```

## เพิ่มสื่อใหม่

1. วางไฟล์ HTML ในโฟลเดอร์วิชานั้น
2. เปิด `index.html` หาบรรทัด `const MATERIALS = [`
3. คัดลอกรายการเดิมหนึ่งบล็อก วางต่อ แล้วแก้ชื่อกับ `url`
4. commit แล้วรอ 1-2 นาที

## หมายเหตุ

- ตั้ง noindex ไว้แล้ว จะไม่ขึ้นใน Google
- `.nojekyll` ป้องกัน GitHub Pages ข้ามไฟล์ที่ขึ้นต้นด้วย `_`
- แยกจาก repo หลักของ KP Science โดยตั้งใจ
