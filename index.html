ห้องเรียนที่บ้าน

สื่อฝึกทั้งหมดรวมไว้ที่เดียว เปิดได้ทั้งคอมและไอแพด

วิธีเพิ่มสื่อใหม่เข้าหน้านี้
  1. วางไฟล์ HTML ไว้ในโฟลเดอร์ของวิชานั้น เช่น chinese/ หรือ physics/
  2. เปิดไฟล์ index.html นี้ แล้วเลื่อนไปที่บรรทัด const MATERIALS = [ ใกล้ท้ายไฟล์
  3. คัดลอกบรรทัดของรายการเดิมหนึ่งบรรทัด วางต่อท้าย แล้วแก้ข้อความกับ url ให้ตรงกับไฟล์ใหม่
  4. บันทึกแล้ว push ขึ้น GitHub — หน้าเว็บจะอัปเดตเองภายในไม่กี่นาที

เพิ่มลงหน้าจอโฮมบนไอแพด: เปิดหน้านี้ใน Safari → ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม จะได้ไอคอนเปิดเต็มจอเหมือนแอป ไม่มีแถบเบราว์เซอร์มากวน
