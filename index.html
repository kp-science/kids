วันนี้หนูอยากเรียนอะไรดี? แตะวิชาด้านล่างได้เลย

สำหรับผู้ปกครอง · วิธีเพิ่มสื่อใหม่เข้าหน้านี้
  1. วางไฟล์ HTML ไว้ในโฟลเดอร์ของวิชานั้น เช่น thai/ math/ science/ chinese/
  2. เปิดไฟล์ index.html นี้ แล้วเลื่อนไปที่บรรทัด const MATERIALS = [ ใกล้ท้ายไฟล์
  3. คัดลอกบรรทัดของรายการเดิมหนึ่งบรรทัด วางต่อท้าย แล้วแก้ข้อความกับ url ให้ตรงกับไฟล์ใหม่ — ถ้าใช้ชื่อวิชาใหม่ที่ยังไม่มี ให้เพิ่มสีและรูปใน SUBJECTS ด้วย
  4. บันทึกแล้ว push ขึ้น GitHub — หน้าเว็บจะอัปเดตเองภายในไม่กี่นาที

เพิ่มลงหน้าจอโฮมบนไอแพด: เปิดหน้านี้ใน Safari → ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม จะได้ไอคอนเปิดเต็มจอเหมือนแอป
